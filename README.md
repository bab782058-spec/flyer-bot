## 生肉チラシbot(meat_flyer_bot.py)について

マルエツ 平間店(トクバイ掲載)のチラシから、**生肉(牛肉・豚肉・鶏肉などの精肉)の特売情報だけ**を自動抽出し、毎朝7時にLINEへ送る追加のbotです。news_bot.pyとは別のスクリプト・別のGitHub Actionsとして動くので、同じ時刻に2通のメッセージ(ニュース+生肉チラシ)が届きます。

### 仕組み

1. トクバイの店舗ページ(`https://tokubai.co.jp/マルエツ/13082`)を通常のHTTPリクエストで取得し、現在掲載中のチラシ一覧(リンク)を抽出
2. チラシごとに、埋め込まれている直接の画像URLを取得
3. 画像をダウンロードし、Geminiの画像認識機能に「生肉の特売情報だけ抽出して」と指示(JSON形式で商品名・価格・割引率を取得)
4. 複数チラシ分の結果をまとめて、カード形式(Flexメッセージ)でLINEに送信
5. 該当する生肉の特売が無い日は「見つかりませんでした」という旨を送信

ヘッドレスブラウザは使わず、チラシページに直接埋め込まれた画像URLを取得するだけなので、構成としてはシンプルです。

### 追加で必要なセットアップ

news_bot.pyと同じSecrets(`GEMINI_API_KEY`、`LINE_CHANNEL_ACCESS_TOKEN`)をそのまま使い回せます。追加の登録は不要です。`meat_flyer_bot.py` と `.github/workflows/daily-meat-flyer.yml` を、同じリポジトリにそのまま追加してください。

### 注意点

- トクバイは「自動取得専用の公式API」を公開しているわけではなく、通常のWebページを直接読みにいく構成です。個人利用・1日1回程度のアクセスを想定しており、高頻度なアクセスやデータの再配布は避けてください
- トクバイ側のページ構造が変わると、チラシや画像URLの抽出に使っている正規表現が効かなくなる可能性があります。動かなくなった場合は、store page のHTML構造を確認し、`get_leaflet_ids` / `get_leaflet_image_url` 内の正規表現を調整してください
- 対象店舗を変えたい場合は、`STORE_PAGE_URL` を別の店舗のトクバイページURLに差し替えてください

## カスタマイズしたくなったら

- ニュースソースを変えたい → `news_bot.py` の `RSS_FEEDS` に好きなRSSのURLを追加・削除
- 配信時刻を変えたい → `daily-news.yml` の `cron` を変更(UTC基準なので、JST希望時刻から9時間引いた値を指定)
- ニュース5選ではなく3選にしたい → `news_bot.py` の `summarize_with_gemini` 内のプロンプト文を書き換える
